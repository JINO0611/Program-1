monday.com 실제 연동

보드 실적을 가져오고, 실제 담당자·메이커 변경을 선택해 전송합니다.

연결 확인 중
실제 연동은 Start_Monday.cmd로 실행하세요. Node.js 22 이상이 필요합니다. index.html을 직접 열면 엑셀 분석 기능을 사용할 수 있습니다.

토큰은 대화창·GitHub에 올리지 마세요. ChatGPT 연결과 이 PC 프로그램의 API 연결은 별개입니다. 토큰 발급은 아래 사용 설명서를 참고하세요.

대상 보드와 각 항목의 열을 연결해 주세요. 금액은 원화 공급가액 등 동일 기준으로 맞춰야 하며 자동 환산하지 않습니다. 회사 자료 전송은 최종 실행 버튼을 눌렀을 때만 진행됩니다.

1. 보드와 항목 연결

담당자 이름과 monday.com 사용자 연결 (People 열 사용 시)

동명이인을 구분하기 위해 사용자 ID를 선택하세요. 지정한 사람 1명으로 전체 담당자 배정을 교체합니다. 텍스트 열에서는 이름을 그대로 전송합니다. 팀·복수 담당자 신규 지정은 지원하지 않습니다.

문서번호·거래처·메이커는 텍스트, 날짜는 날짜, 금액은 숫자 열에 연결합니다. 담당자는 텍스트 또는 People 열을 지원합니다. 외부 연동키는 신규 등록 중복 확인용 텍스트 열이며 보드에서 미리 만들어 주세요. 상태·드롭다운·연결보드·수식·미러 열과 하위항목은 이번 버전의 연결 대상에 포함하지 않습니다. 한 보드의 활성 일반 항목만 읽습니다.

2. 가져오기 / 선택 전송

monday.com → 분석 프로그램

연결한 보드의 전체 활성 항목을 미리 읽습니다. 적용 시 현재 자료 중 선택한 종류 전체를 교체합니다.

분석 프로그램 → monday.com

담당자·메이커 설정에서 전송할 행을 선택하세요. 최대 50행씩 검토합니다. 기존 항목은 담당자·메이커만 변경하며, 신규 항목은 연결한 필드를 등록합니다.

자동 동기화는 하지 않습니다. 전송 실패 시 확인된 성공 행까지만 표시하고 중단합니다. 신규 등록 결과가 불확실하면 보드에서 확인 후 다시 검토하세요. 여러 사람이 동시에 등록하면 연동키 중복이 발생할 수 있습니다.

이번 버전의 분석 기준

3개년 동기간 비교
기준연도와 앞선 2개년을 비교합니다. 기본 종료일은 기준연도의 견적·발주 자료 중 더 이른 말일입니다. 같은 월·일로 과거 연도의 범위를 맞춥니다. 연간 전체 모드에서는 각 연도의 제공된 자료를 모두 합산하므로 기준연도가 미마감이면 비교에 주의해 주세요.
원본 열의 연결
사업장 = 거래처, 브랜드 = 메이커, 견적 작성자 = 담당자, 뒤쪽 부서 열 = 영업팀, T/P(원) = 행별 금액입니다. 고객명은 담당 개인이므로 거래처로 사용하지 않습니다. 문서번호에 적힌 연도가 아닌 실제 견적일·발주일로 연도를 나눕니다.
금액과 건수
T/P(원)을 그대로 합산합니다. 수량을 다시 곱하지 않습니다. 동일 문서의 여러 품목은 금액을 합산하고 건수는 문서번호 하나당 1건입니다. 취소·반품·수정 이력은 원본에 반영된 상태를 그대로 따릅니다.
파일 중복
유효 분석 데이터 전체가 같은 원본 시트는 한 번만 반영합니다. 서로 다른 파일의 일부 행만 겹치는 경우는 자동 삭제하지 않고 경고합니다. 이전 견적과 수정 견적의 구분은 원본 정리 기준에 따라야 합니다.
빈 서식 행
엑셀 뒤쪽의 값 없는 서식 행은 제거합니다. 파일의 행 번호가 백만 행이어도 실제 값이 있는 원본 행을 찾아 처리합니다.
증감률
(현재 실적 − 전년 실적) ÷ 전년 실적입니다. 전년 금액이 0 이하이거나 전년 자료가 없으면 증감률을 표시하지 않습니다. 자료 미제공과 제공된 자료의 실적 0은 구분합니다.
발주 전환율
제공 자료에는 견적과 발주를 연결하는 원견적번호가 없습니다. 문서번호가 비슷하다는 이유로 추정 연결하거나 발주금액/견적금액을 전환율로 표시하지 않습니다.
프로젝트·원가
연도별로 프로젝트·원가 열의 구성이 다릅니다. 이 버전의 주 비교 범위는 견적·발주 금액과 건수이며, 누락 항목은 미기재로 보관합니다.

담당자·메이커 수정

담당자·메이커 설정에서 행별 설정 또는 선택 항목 일괄 지정을 사용합니다. 새 이름을 직접 입력할 수 있으며, 비워 둔 항목은 유지합니다. 원래 값은 행 아래에 표시되며 수정 결과가 모든 분석에 반영됩니다. 직전 변경 취소는 현재 실행 중 마지막 변경 1회를 되돌립니다. 수정 내용은 데이터 백업에 포함됩니다. 다시 실행할 때 백업 복원으로 열어 주세요. 새 엑셀 불러오기 시 이전 수정값을 자동 이월하지 않습니다.

자료 불러오기와 보관

  1. 파일 묶음 불러오기에서 3개년 견적·발주 XLSX 파일을 함께 선택합니다. 시트와 열을 자동 인식합니다.
  2. 적용 전에 중복·제외 행·자료 기간을 확인합니다. 적용하면 기존 자료 전체를 교체합니다.
  3. 엑셀 수식은 계산하지 않고 저장된 계산 결과만 읽습니다. 결과가 없는 수식 셀은 값으로 붙여넣어 주세요.
  4. 기본 분석은 PC에서 처리합니다. monday.com 연동에서 검토 후 실행하면 선택한 자료를 대상 보드로 전송합니다. GitHub에는 코드만 저장합니다.
  5. 추가로 불러온 자료는 종료 전에 데이터 백업으로 저장합니다. 실적 포함 배포본은 다시 열면 처음 첨부한 자료가 열립니다.
